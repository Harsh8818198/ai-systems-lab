# ai-systems-lab

My working repo for learning to build and train neural networks from scratch. Everything here is typed by me, not copied.

## What is in here

- `zero-to-hero/` code written while working through Andrej Karpathy's "Neural Networks: Zero to Hero", one folder per video
- `cs336/` my work on the Stanford CS336 "Language Modeling from Scratch" assignments
- `drills/` small from-scratch implementations and practice problems
- `replications/` papers I rebuilt, each with a write-up of what matched and what did not
- `log/` three lines a day: what I learned, what confused me, what is next

## Setup

```
uv venv --python 3.11 .venv
uv pip install --python .venv numpy matplotlib jupyter ipykernel
```
